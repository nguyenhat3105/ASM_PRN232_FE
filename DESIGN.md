# TaskTrack interface

Visual direction: [Atlas — Productivity Dashboard by Reyhan Adinata](https://dribbble.com/shots/27000613-Atlas-Productivity-Dashboard).

The implementation uses a white and pale blue workspace, cobalt navigation and actions, thin borders, compact typography, project progress rows and a task status donut. The TaskTrack name and existing application workflows are retained. No reference artwork or fictional users, activity, notifications or metrics are embedded.

`app/atlas.css` applies the shared theme to all routes, including management tables, dialogs, board and calendar. The overview uses existing API data. Header search submits to task search; create actions open the existing task form.

The sidebar switches to a mobile drawer. Wide data tables and the calendar scroll within their panels. Reduced-motion preferences disable decorative transitions.
